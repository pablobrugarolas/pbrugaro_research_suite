# Pbrugaro GTD

This skill wraps the GTD / warrant-first research system imported from Scott Cunningham's `MixtapeTools/gtd` folder.

## Source And Attribution

- Source repo: https://github.com/scunning1975/MixtapeTools
- Imported path: `gtd/`
- Local suite path: `external/mixtapetools/gtd/`

Treat this as an external research tool included in the Pbrugaro Research Suite, not as original suite content.

## Communication Principle

When invoking this tool for the first time in a thread, tell Pablo that you are using the GTD / warrant-first tool from the research suite and explain why in one practical sentence.

## When To Use

Use this tool when the task is about:

- turning a conjecture into a precise, falsifiable hypothesis
- tracking empirical insights with provenance
- recording binding design decisions
- checking whether figures, tables, or outputs are fresh relative to scripts
- organizing recoverable research state across sessions
- stress-testing whether a causal claim has earned its warrant

## Pbrugaro Defaults

For empirical economics projects, treat Stata as the default language for data cleaning and main reduced-form workflow unless the project already uses another pipeline. Use this GTD tool to structure claims, warrants, decisions, and freshness checks around that workflow rather than replacing it.
